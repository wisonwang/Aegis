数据集管理

数据集是构建在数据源之上的受治理数据产品：有稳定名称（消费句柄）、有定义 SQL、有生命周期（草稿 → 发布）。Agent 消费已发布且已授权的数据集；其表/行/列治理与底层表共用同一套引擎（按 table_name = 数据集名称 关联）。

语义指标层

由管理员预定义的受治理业务指标（如「各地区客户数」）。运行指标时，参数被安全地渲染进 SQL 模板，并经由同一套受治理执行链路运行，同时返回血缘（涉及哪些表 / 是否含 PII）。

指标定义管理（管理员）

管理员可在此创建、删除指标定义。指标名称在数据源内唯一，参数在 SQL 模板中以 :name 引用。
