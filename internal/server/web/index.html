Aegis API 接入文档

本文档说明如何以编程方式接入 Aegis 的数据供给能力：DataAPI（REST）面向应用与服务，MCP面向 AI Agent。所有接口均经过同一套治理引擎（表/行/列权限、脱敏、审计），默认拒绝未授权访问。

1. 基础信息

项值
Base URLhttp://HOST:PORT（即配置 listen_addr，管理后台同址 /admin/）
协议HTTP / HTTPS（生产建议 HTTPS）
内容类型application/json
字符集UTF-8

2. 认证

除登录接口外，所有 DataAPI 请求必须在请求头携带 JWT：

Authorization: Bearer YOUR_JWT_TOKEN

获取令牌：

curl -X POST http://HOST:PORT/api/v1/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"analyst","password":"analyst123"}'

响应：

{
  "token": "eyJhbGciOi...",
  "user": {
    "id": "u_xxx",
    "username": "analyst",
    "display_name": "分析师",
    "roles": ["analyst"],
    "attributes": {"tenant": "acme"}
  }
}

JWT 有过期时间（配置 jwt_expiry）；过期后请重新调用登录接口换取新令牌。MCP 还支持静态 API Key 鉴权，见第 6 节。

3. DataAPI 端点总览

方法路径说明鉴权
POST/api/v1/login用户名密码换取 JWT公开
GET/api/v1/me当前用户信息Bearer
POST/api/v1/query执行受治理的 SQL/查询Bearer

4. 核心端点示例

4.1 列出数据源

curl http://HOST:PORT/api/v1/datasources \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN'

响应：

{
  "datasources": [
    {"id":"ds_xxx","name":"mysql-local","type":"mysql"}
  ]
}

4.2 列出可访问的表

curl 'http://HOST:PORT/api/v1/datasources/mysql-local/tables' \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN'

响应：

{
  "tables": [
    {"name":"orders","ops":["SELECT"]},
    {"name":"customers","ops":["SELECT","INSERT"]}
  ]
}

4.3 执行查询

请求体：

{
  "datasource": "mysql-local",
  "sql": "SELECT id, customer, amount FROM orders WHERE status = 'paid' LIMIT 10",
  "params": [],
  "session_id": "optional-chat-id"
}
curl -X POST http://HOST:PORT/api/v1/query \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"datasource":"mysql-local","sql":"SELECT 1"}'

响应（查询类）：

{
  "columns": ["id","customer","amount"],
  "rows": [
    {"id":1,"customer":"Alice","amount":99.5}
  ],
  "rewritten_sql": "SELECT id, customer, amount FROM (SELECT * FROM orders WHERE tenant_id = 'acme') t WHERE status = 'paid' LIMIT 10",
  "truncated": false,
  "session_id": "optional-chat-id"
}

rewritten_sql 是经治理改写后的实际执行 SQL：行策略被注入为派生表、列按授权投影、:attr 占位符由调用者 JWT 属性代入（上例 :tenant 被替换为 'acme'）。写操作（INSERT/UPDATE/DELETE）返回 affected_rows 而非 rows。truncated 为 true 表示结果被 max_rows 截断。

4.4 查询成本评估（不执行）

curl -X POST http://HOST:PORT/api/v1/datasources/mysql-local/query/estimate \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"sql":"SELECT * FROM orders"}'

该接口会把语句跑一遍治理改写并生成执行计划（EXPLAIN），但不读取/写入任何数据。Agent 可据此决定是否需要收紧过滤条件、规避大表全扫或谨慎处理 PII。

4.5 获取受治理语义目录（供 AI）

curl 'http://HOST:PORT/api/v1/datasources/mysql-local/catalog' \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN'

响应（节选）：

{
  "datasource": "mysql-local",
  "tables": [
    {
      "name": "orders",
      "description": "订单表",
      "row_scoped": true,
      "columns": [
        {"name":"id","type":"bigint","description":"订单号","masked":false},
        {"name":"phone","type":"varchar","description":"手机号","masked":true}
      ]
    }
  ]
}

目录仅包含调用者有权访问的表与列，并带有业务描述、同义词与脱敏标记（masked）。这正是 NL2SQL 网关喂给模型的内容。

4.6 NL2SQL 安全网关

curl -X POST http://HOST:PORT/api/v1/datasources/mysql-local/nl2sql \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"question":"上海客户的姓名和手机号","sql_hint":""}'

响应：

{
  "generated_sql": "SELECT name, phone FROM customers WHERE city = '上海'",
  "explanation": "根据语义目录将自然语言映射为查询",
  "query_result": {"columns":["name","phone"],"rows":[...],"rewritten_sql":"...","session_id":"..."},
  "session_id": "..."
}

生成的 SQL 仍经由同一套受治理执行链路运行——表/行/列权限、脱敏、审计全部生效，且仅允许只读查询。

6. MCP 接入（AI Agent）

MCP 以 JSON-RPC 2.0 over HTTP 暴露，供 AI Agent 自动发现工具与数据目录。端点默认 POST /mcp（路径由 mcp.path 配置），支持 Accept: text/event-stream 的 SSE 流式响应。

鉴权（二选一）：

Authorization: Bearer YOUR_JWT_TOKEN
# 或静态服务账号密钥（需服务端配置 mcp.api_key，且存在 mcp-agent 用户）
X-MCP-API-Key: YOUR_API_KEY

握手流程：initialize → notifications/initialized → 调用工具/资源/提示。

可用能力：

  • tools/list / tools/call：工具如 query、nl2sql、get_catalog
  • resources/list / resources/read：受治理 schema 资源，URI 形如 aegis://<name>/schema
  • prompts/get：提示如 nl2sql（注入 schema 与安全规则）

示例：初始化

curl -X POST http://HOST:PORT/mcp \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"my-agent","version":"1.0"}}}'

示例：调用 query 工具

curl -X POST http://HOST:PORT/mcp \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"query","arguments":{"datasource":"mysql-local","sql":"SELECT 1"}}}'

7. 治理模型（接入必读）

  • 默认拒绝：未显式授权的表/列/行不可访问。
  • 行策略：多角色按优先级合并（AND），注入为派生表；:attr 由调用者 JWT 属性代入。
  • 列脱敏：在结果层执行（phone/email/card/partial/hash/redact/tokenize/fpe）；admin 角色绕过治理。
  • 审计：每次调用写入 audit_logs，含渠道（dataapi / mcp）与 session_id，可在「审计日志」页检索。
  • AI 护栏：max_rows 截断、query_timeout 超时、按主体限流、无 WHERE 写操作默认拒绝。

9. Python 快速上手

import requests

BASE = "http://localhost:8080"

# 1) 登录换取令牌
r = requests.post(BASE + "/api/v1/login",
                  json={"username": "analyst", "password": "analyst123"})
token = r.json()["token"]
hdr = {"Authorization": "Bearer " + token}

# 2) 列出数据源
print(requests.get(BASE + "/api/v1/datasources", headers=hdr).json())

# 3) 执行受治理查询
q = requests.post(BASE + "/api/v1/query", headers=hdr,
                  json={"datasource": "mysql-local",
                        "sql": "SELECT 1"})
print(q.json())
