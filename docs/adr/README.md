# Aegis 架构决策记录（ADR）

本目录收录 Aegis 的关键架构决策，采用 [ADR 模板](https://adr.github.io/) 风格：记录**为什么**（Context）而不仅是**做了什么**（Decision）。

> 决策状态：`Proposed` 待评审；`Accepted` 已采纳；`Deprecated` 已弃用；`Superseded by ADR-XXX` 被新决策取代。

## 决策原则（适用于本目录所有 ADR）

- **无架构太空步**：每个抽象必须证明其复杂性合理。
- **权衡优先于最佳实践**：说出放弃了什么，而不只是得到了什么。
- **领域先于技术**：先理解业务问题，再选工具。
- **可逆性优先**：优先选易于变更的决策，而非"最优"但锁死的决策。
- 所有决策服务同一个内核不变式：**治理不可被绕过**（LLM/指标/估算生成的 SQL 都走同一 `permission.Rewrite` 路径）。
